# Development Agent

The Development Agent generates production-quality Go code for Kubernetes and OpenShift, following strict security and quality standards. It receives the Design Agent's outputs from shared state and produces code files, test files, and a PR description.

**File:** `agents/go_k8s_developer.py`
**Entry point:** `run_development(context, repo_path)`

---

## Inputs

The agent reads from a context dictionary, which is populated from `AgentState` when running inside the orchestrator.

| Key | Type | Required | Description |
|-----|------|----------|-------------|
| `issue_title` | str | Yes | Feature or bug title |
| `design_analysis` | str | Yes | Design document from Design Agent |
| `implementation_plan` | list[str] | Yes | Ordered implementation steps |
| `impacted_components` | list[str] | No | Components affected |
| `acceptance_criteria` | list[str] | No | Testable criteria |
| `risks` | list[str] | No | Risks from design phase |

---

## Outputs

```python
{
    "code_files": list[dict],         # [{path, content, description}]
    "test_files": list[dict],         # [{path, content}]
    "code_changes": dict[str, str],   # file path → change description
    "files_modified": list[str],      # flat list of modified file paths
    "pr_description": str,            # PR description with "Generated by AI" footer
    "security_notes": list[str],      # Security considerations
    "dependencies": list[str],        # New Go module dependencies required
    "next_steps": list[str]           # Recommended follow-up actions
}
```

## Code Quality Standards

All generated code follows these rules:

- **Idiomatic Go** - Meaningful names, focused functions, standard library preferred
- **Go doc comments** - All exported types, functions, and methods have doc comments
- **TLS 1.3** - Enforced wherever TLS configuration is added or modified
- **No hardcoded secrets** - Credentials always read from environment variables
- **Structured logging** - Uses `logr` format, never logs sensitive data
- **Proper error handling** - Errors are wrapped with context using `fmt.Errorf("...: %w", err)`
- **Context propagation** - `context.Context` passed through the full call chain
- **Table-driven tests** - Mock-based unit tests with multiple scenarios

## Direct Invocation

```python
from agents.go_k8s_developer import run_development

context = {
    "issue_title": "Add TLS 1.3 support to build controller",
    "design_analysis": "# Design: Add TLS...\n\n## Problem Statement\n...",
    "implementation_plan": [
        "Add TLS configuration struct to config package",
        "Update HTTP server initialization to enforce TLS 1.3"
    ],
    "impacted_components": ["build_controller"],
    "acceptance_criteria": ["All connections use TLS 1.3 minimum"]
}

result = run_development(context)

for code_file in result["code_files"]:
    print(f"File: {code_file['path']}")
    print(f"Description: {code_file['description']}")
    print(code_file["content"])
    print("---")

print("Security notes:")
for note in result["security_notes"]:
    print(f"  - {note}")
```

## Generated Code Patterns

### TLS Configuration

```go
// Enforce TLS 1.3
tlsConfig := &tls.Config{
    MinVersion: tls.VersionTLS13,
}
```

### Secret Handling

```go
// Read credentials from environment - never hardcode
apiKey := os.Getenv("API_KEY")
if apiKey == "" {
    return fmt.Errorf("API_KEY environment variable not set")
}
```

### Error Handling

```go
result, err := DoSomething(ctx, input)
if err != nil {
    return fmt.Errorf("failed to process input: %w", err)
}
```

### Controller Reconciliation

```go
func (r *Reconciler) Reconcile(ctx context.Context, req ctrl.Request) (ctrl.Result, error) {
    log := logr.FromContextOrDiscard(ctx)

    resource := &v1.BuildRun{}
    if err := r.Get(ctx, req.NamespacedName, resource); err != nil {
        return ctrl.Result{}, client.IgnoreNotFound(err)
    }

    log.Info("reconciling buildrun", "name", resource.Name)
    return ctrl.Result{}, nil
}
```

## PR Description Format

Generated PR descriptions always include a structured format and an "Generated by AI" footer:

```markdown
## Summary
[Concise summary of what changed and why]

## Changes
- [Key change 1]
- [Key change 2]

## Security Considerations
- TLS 1.3 enforced for all new connections
- No secrets logged or hardcoded

## Testing Performed
- Unit tests added for all new logic
- Integration tests updated

---
Generated by AI
```
