# Logs Directory

This directory contains log files generated by the multi-agent system.

## Structure

- `agents/` - Agent execution logs (design, development, testing, docs)
- `dashboard/` - Dashboard backend and API logs
- `tests/` - Test execution logs
- `sessions/` - Session-specific logs with detailed traces

## Log Rotation

Logs are rotated daily and kept for 30 days by default.

## Log Levels

- DEBUG - Detailed diagnostic information
- INFO - General informational messages
- WARNING - Warning messages
- ERROR - Error messages
- CRITICAL - Critical errors requiring immediate attention

## Log Format

```
[TIMESTAMP] [LEVEL] [AGENT/COMPONENT] - Message
```

Example:
```
[2026-03-12 14:30:45] [INFO] [design_agent] - Starting design analysis for issue #123
```
